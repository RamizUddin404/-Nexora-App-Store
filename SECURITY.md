# Security Policy

## Supported version

Security fixes are intended for the latest code on the `main` branch.

## Reporting a vulnerability

Please do not publish credentials, personal data, or exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is available. If it is not available, contact the repository owner privately through their GitHub profile: https://github.com/RamizUddin404.

Include the affected page or file, impact, reproduction steps, and any safe proof of concept.

## Security notes

NEXORA is a static front-end. It does not currently provide server-side authentication, user accounts, file uploads, or a shared database. Never enter secrets into the website or commit credentials to this repository. Review third-party links and downloads before opening or running them.
